You will need the new firmware file 'as7341-unicom-fw_v0.10.0.dfu' and the installed software 'DfuSe_Demo' in case of updating the Presense Unicom Firnare. All data's are in the FW Upload directory.

It is very explicit that you must disconnect the sensor board and press the DFU button while re-connecting Unicom board without conncted sensor board to computer. Therefore, follow the steps:

•	Disconnect Unicom board from PC
•	Disconnect sensor board from Unicom board
•	There is a DFU button on the left side of the USB connector on the Unicom.  Press and hold that button while connecting Unicom board directly to laptop (no hub).  Once connected, release button.
•	If the Unicom board is in the correct mode you should see the connected 'STM Device' in the 'Available DFU Systems'
•	Click on the Choose button and select desired .dfu file
•	Click on Upgrade and the upgrade process will start
•	After seconds, the process vill be finished with a message 'Upgrade successful'
