
Relato de caso dos testes realizados no dia 5 de nov/24

LED RGBW de aprox. 3W de luz verde foi usado para avaliar a resposta especral do sensor AS7341
Em anexo imagens do sinal de * backgroun [Led Desligado]
                             * Funcao espcral na situacao do LED verde acionado


Fez-se uso de uma fenda com diametro de aprox. 1,2mm a qual intensifica os picos da luz verde [aprox. 500-550nm]

Os gráficos apresentados foram obtidos a partir do comparilhamento da potencia espectral e seu respectivo comprimento de onda
via UART entre o microcontrolador TIVAC4 e um script python rodando em um PC externo
